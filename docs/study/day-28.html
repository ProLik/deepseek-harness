一、从零开始的概念讲义

先建立词义和因果关系，再阅读本页后面的源码卡片。下面每一节都要能用自己的话复述。

Web profile 没有复制 Agent Loop

web-app bundle 在同一 core spine 上增加 host、API gateway、controllers、client modules 和 UI。浏览器发消息最终仍调用 Agent.followup。

因此核心事件改变会影响 Web、SDK 和 Python 等多个投影面。

具体例子

Web 的“发送”不是直接调用模型 HTTP，而是经 controller 找到 Agent。

网络层与业务层分开

Gateway 处理传输、认证、远程错误和流。Controller 解释业务请求并调用 Session/Agent/Settings 等 Service。Client connection 处理浏览器端 RPC。

网络 parser 验证外部 JSON，进入同进程 typed service 后不重复敌意校验。

具体例子

非法 remote frame 在 gateway 拒绝，不应到 React 组件才发现。

UI 从 events 和 metadata 派生

工具卡片、消息状态和轨迹应从持久 Session events 生成。Presenter 保持纯函数，刷新或 resume 后可以重建。

只保存在组件 local state 的模型可见或历史事实会在刷新后消失。

具体例子

tool/call 与 tool/result 加 presenter metadata，足以重建工具卡片，不依赖当时运行的 Promise。
