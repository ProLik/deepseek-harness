一、从零开始的概念讲义

先建立词义和因果关系，再阅读本页后面的源码卡片。下面每一节都要能用自己的话复述。

完整能力必须回答三个问题

Definition 回答“调用者可以请求什么”；Provider 回答“实际怎样完成”；Consumer 回答“产品中的谁使用它”。只有接口没有实现、只有 provider 没有消费者，都不是完整能力。

读陌生 group 时先找 group README 的家族地图，再用 package.json 依赖验证角色，不凭 package 名称猜。

具体例子

shell Definition 定义请求/spec；local 或 pwsh provider 执行；tool-bash/tool-pwsh 将能力提供给模型。

依赖方向决定可替换性

Consumer 的 package.json 应依赖 Definition package。Provider 也依赖 Definition 来实现接口或注册。Consumer 不依赖 provider，bundle 同时选择双方。

测试 provider 与正式 provider 因此可以替换，而测试无需修改 Consumer。

具体例子

Agent Loop 依赖 dsh-llm；llm-deepseek 独立依赖 dsh-llm；bundle 把二者组合。

Bundle 是部署选择，不是第四种业务实现

Bundle patch 插入插件行并提供 Config。它不应复制 provider 的请求代码，也不应把 Consumer 行为写在 YAML 表达式中。

一个 provider 可被多个 profile 选择；一个 profile 也能选择不同 provider。

具体例子

JSONL 与 SQLite 都实现 session persistence；profile 决定挂哪一个，Session 语义不改变。
