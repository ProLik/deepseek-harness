系统提示由多个插件协作组装

身份、persona、计划规则、工具说明等由各自拥有者注册，不集中维护一个巨型字符串。SystemPrompt 按 name 管唯一性，按 order 稳定排序。

Section、Context、Variable 不能混用

Section 是系统指令；Context 是某次请求动态物化的用户角色快照；Variable 是渲染占位值。它们进入模型请求和日志的方式不同。

实际 assemble 结果必须写入 request 快照，不能只依赖当前 registry 状态。

具体例子

当前 cwd 可能作为动态 context 或变量参与；恢复旧请求时使用当时记录值，而不是新的 cwd。

Waterfall 保持专家扩展点

基础 registry 先收集贡献，再触发 system-prompt/assemble waterfall。Listener 可合作调整 assembly，但必须 next。

complete section 声明完整系统 prompt，也不能阻止 waterfall 解析 tools、contexts 和 variables；最后再恢复完整 section 约束。

具体例子

complete 不是“跳过所有扩展”，而是对最终 system sections 的所有权声明。
