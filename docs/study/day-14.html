模型消息不是字符串数组

LLM 请求需要区分谁说话，以及内容是文本、图片、推理还是工具调用。Message 用 role 区分消息，content 再由不同 block 组成。

结构化类型让 Session 能无损记录，也让 provider adapter 在翻译 API 时保留关联信息。
