六、常见误区与自测

小白最容易卡住的地方

误区：所有 checkpoint 都是同一种东西

先区分投影缓存与模型上下文事实。

误区：SQLite schema version 就是 Session format version

它们拥有者和兼容范围不同。

误区：Compaction 等于删除数据库历史

它改变模型上下文派生，具体持久事实仍受日志规则管理。

闭卷自测

先在纸上回答，再展开答案。答错不是失败；回到本页对应源码站的卡片找证据。

1. compaction 等于删日志吗？

不是该概念；它记录摘要/checkpoint并改变后续模型上下文。

2. checkpoint 为何可丢？

它是缓存，可从 canonical events 重新 reduce。
