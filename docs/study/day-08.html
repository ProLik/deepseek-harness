六、常见误区与自测

小白最容易卡住的地方

误区：process.argv[0] 就是第一个用户参数

前两个元素通常是 Node 可执行文件和脚本路径，bin.ts 使用 slice(2)。

误区：-- 后仍由 dsh parser 解释

-- 是职责分隔；剩余字符串原样交给应用。

误区：解析成功代表 profile 一定能启动

解析只证明调用结构有效；配置、依赖和运行时仍可能失败。
