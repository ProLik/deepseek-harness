小白最容易卡住的地方

误区：新增模型要在 Agent Loop 加 if(provider)

循环应依赖 LlmRuntime，provider 通过 adapter 注册。

误区：缺 model 时 run 内随便选默认

默认值应由拥有方显式 resolve，并能写入请求快照。

误区：Mock 测试可以替代 Provider 测试

Mock 证明 Consumer；真实翻译和协议必须由 provider 测试。
