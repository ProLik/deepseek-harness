Turn 与 Step 是一对多

简单文本回答只需要一个 step。模型请求工具时，第一个 step 产生 tool call/result，第二个 step 把结果发回模型并得到最终文本。

Turn 提供用户工作范围和结束原因；Step 提供每次模型请求边界。

具体例子

turn/start → step1 → tool → step/end → step2 → answer → step/end → turn/end。

先写控制事件，再执行阶段

turn() 领取输入后 append turn/start；每次 step 前 append step/start，并在相应结束路径 append step/end/turn/end。

这些事实让 UI、SDK、统计和恢复看到相同生命周期，不靠内存 status 猜。
