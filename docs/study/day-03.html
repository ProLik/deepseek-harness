六、常见误区与自测

小白最容易卡住的地方

误区：TypeScript 类型会自动验证网络或模型数据

类型在编译后不会替你检查外部 JSON；第 21 天会学习 JSON Schema。

误区：void 表示函数没有行为

void 只表示没有有用返回值；函数仍可能入队、写日志或发事件。

误区：interface 可以直接 new

interface 只存在于类型系统，必须由 class 或对象实现。
