公共接口隐藏循环内部调度

Web、SDK、ACP 只需要 followup、cancel、whenIdle、status 和 session。它们不应调用 private turn/step。

接口让不同外部入口共享同一循环，也使 Agent Loop 可以在不破坏调用者的情况下调整内部调度。

具体例子

followup 返回 void，因为它提交工作；完成由 whenIdle、status 或 Session events 观察。

Inbox 处理输入到达时间

输入可能在 idle、模型流中或工具执行中到达。Inbox 用 target 区分下一 turn 与下一 step，循环在明确边界 claim/splice。

队列变化会记录 agent/inbox 事件，避免恢复后丢失已影响模型的输入。

具体例子

next-step 输入能改变当前 turn 后续模型请求，因此必须模型可见且可重建。

状态和完成不是同一个 Promise

Agent status 只表示当前是否 running；followup 可能在返回后才启动 drain。whenIdle 等待队列和当前运行达到稳定 idle。

外部入口要遵守公共完成语义，不用 setTimeout 猜模型是否结束。

具体例子

测试先 followup 再 await agent.whenIdle()，而不是等待固定 100ms。
