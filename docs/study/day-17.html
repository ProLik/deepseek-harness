六、常见误区与自测

小白最容易卡住的地方

误区：seq 就是 events 数组下标

seq 是持久协议事实，数组切片或 prefix 读取时不能用下标替代。

误区：TypeScript 能验证磁盘 JSON

磁盘数据在运行时边界，必须解析版本、envelope 和事件类型。

误区：所有 UI-only 事件都可自动忽略

必须由生产者明确标记，并评估投影和模型影响。
